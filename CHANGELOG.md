# Changelog

## 1.1.0

- Added local Enable all / Disable all controls and individual feature switches.
- Added independently paused Mobile and Wi-Fi rules, with Block all and Allow all for each network.
- Added distinct Mobile/Wi-Fi tabs and seven-day charts.
- Added a visible, draggable animated landscape with snowfall, clouds, and a skier, plus page transitions and button ripples.
- Explained animation pauses caused by app settings, Android Battery Saver, or disabled system animations.
- Added explicit Android Private DNS enable/disable setup actions.
- Preserved saved rules when features are disabled.
- Increased versionCode to 2 and kept the signing certificate for in-place updates.

## 1.0.0

Initial native data monitor and selective local VPN firewall. Android runtime behavior was not verified in the available environment.
