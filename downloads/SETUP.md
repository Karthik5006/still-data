# Still Data for your Galaxy S25 Ultra

Install `StillData-1.0-release.apk`, open it, and:

1. Grant Usage Access from Overview to see Android's real per-app and device data totals.
2. In Apps, turn off Mobile access or Wi-Fi access for apps to block.
3. In Guard, tap Enable firewall and approve Android's VPN prompt.
4. For ad blocking, tap Set up ad blocking in Guard and follow the Private DNS instructions. Check its connected status after saving.

Your website has not been changed. Still Data is a separate native app with an original peaceful mountain interface. No root, account, or server is required. Another VPN cannot run at the same time as its app firewall.

This is a first locally signed build. Compilation, APK signature, manifest checks, and 16 core logic checks passed. Runtime behavior has not yet been verified on an Android device; the available emulator could not complete startup. Private DNS does not remove every ad, and the displayed budget is a guide rather than an automatic cutoff.

The source archive contains an Android Studio project, Gradle wrapper, original artwork, build scripts, and documentation. It excludes build-tool downloads, generated test artifacts, and the signing key.
