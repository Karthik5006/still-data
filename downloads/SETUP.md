# Still Data for your Galaxy S25 Ultra

Install `StillData-1.1-release.apk`, open it, and:

1. Grant Usage Access from Overview to see Android's real per-app and device data totals.
2. On Overview, Enable all / Disable all controls local features. Guard and Settings also have individual switches.
3. In Apps, choose Mobile data or Wi-Fi. Each network has its own rule switch, Block all / Allow all buttons, and per-app access switches.
4. In Guard, tap Enable firewall and approve Android's VPN prompt.
5. For ad blocking, tap Enable ads filter in Guard and follow the Private DNS instructions. Check its connected status after saving.

Your website has not been changed. Still Data is a separate native app with an original peaceful mountain interface. No root, account, or server is required. Another VPN cannot run at the same time as its app firewall.

This is a first locally signed build. Compilation, APK signature, manifest checks, and 37 core logic checks passed. Runtime behavior has not yet been verified on an Android device; the available emulator could not complete startup. Private DNS does not remove every ad, and the displayed budget is a guide rather than an automatic cutoff.

The source archive contains an Android Studio project, Gradle wrapper, original artwork, build scripts, and documentation. It excludes build-tool downloads, generated test artifacts, and the signing key.

Animations: open Overview to see the live snow, clouds, and skier, and drag the landscape sideways. If motion is paused, the app explains why. Enable Animations in Settings. On Samsung, check Accessibility → Vision enhancements → Remove animations and Android Power saving if needed.

Disable all does not change Android’s external Private DNS setting. Use Disable ads filter in Guard and choose Automatic or Off in Android settings to stop that system filter.
